## 🚀 About Me

- Developing **VocaNova**, a vocabulary learning and testing system with an ASP.NET Core API, MVC dashboard, Flutter mobile app, and xUnit tests.
- Building **Comic Management**, a full-stack comic reading platform with .NET microservices, a YARP API Gateway, internal gRPC communication, and a React/Vite frontend.
- Working with both relational data and application infrastructure, including MySQL, SQL Server, Redis, RabbitMQ, and Docker Compose.
- Exploring practical integrations such as Google OAuth, Cloudinary, automated text translation, and VietQR/SePay payments through project work.
